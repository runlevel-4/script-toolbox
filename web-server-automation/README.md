# Web Server Automation

Shell scripts for automating web server and application setup on Linux.

## Purpose

This repository section provides repeatable scripts for installing and configuring web applications and related services.

## Prerequisites

- A Linux server
- A user with `sudo` privileges

## Usage

Clone the repository:

```bash
git clone https://github.com/runlevel-4/script-toolbox.git
cd script-toolbox/web-server-automation
```
